# DasbodhByEmail

Material from a study of the Dasbodh, the Marathi spiritual classic of Samarth Ramdas Swami, followed through an
email-based learning course. This is a reference collection, not an active track: it is kept for the maintainer's
own study and for anyone who wants to see how such a course was organised.

## What is in the folders
| Folder | What it holds |
|---|---|
| `Admin/` | The course's own guidance documents (the file names speak of the study plan, `abhyas`, and the study method, `abhyaspaddhat`) |
| `Assignments/` | The course text and its covers in several formats, and the learners' assignment sets by level (Parichay, Prabodh, Pravesh). Some entries are the maintainer's own coursework; those are flagged for review in `reports/STATUS.md` |
| `References/` | A list of the Dasbodh texts, pictures and course papers that used to be kept here (the files themselves are no longer in the repository) |
