# AthaYoga: Yoga Sutras with notes

Notes on the Yoga Sutras from the AthaYoga pages on Sanskrit Documents. Copies of the pages were once kept here as
PDFs. They are not in this repository any more, because they belong to their authors. Read them at the source:

- All sutras: https://sanskritdocuments.org/sites/athayoga/sutras.html
- Notes, by chapter: https://sanskritdocuments.org/sites/athayoga/sutra_ch1n.html, https://sanskritdocuments.org/sites/athayoga/sutra_ch2n.html, https://sanskritdocuments.org/sites/athayoga/sutra_ch3n.html, https://sanskritdocuments.org/sites/athayoga/sutra_ch4n.html
- One more notes page for the last chapter: https://sanskritdocuments.org/sites/athayoga/sutra_ch4phn.html

See [NOTICE.md](../../../NOTICE.md) for how this repository treats third-party material. If you are the author and
want something changed, open an issue.
