# Yoga Sutra Study

Pages from the Yoga Sutra Study site: an about page, an introduction, translations, the Sanskrit text and the sutras
chapter by chapter with commentary. The Yoga Sutra slides in this repository use its interpretations, tagged with
initials; see [NOTICE.md](../../../NOTICE.md). Copies of the pages were once kept here as PDFs. They are not in this
repository any more, because they belong to their author. Read them at the source:

- Site: http://yogasutrastudy.info/
- Audio recordings of the sutras: http://yogasutrastudy.info/links/ysp-multi-track.html
- About the maintainer: http://yogawithsubhash.com/about/

## What stays in this folder
`YogSutra_Devnagari.txt` is the Devanagari text of the sutras. It is kept because it is the repository's only copy of
the Sanskrit text, and the sutras themselves are an ancient text. If you reuse it, check the source site first for how
it should be credited.

If you are the author of the site and want something changed, open an issue.
