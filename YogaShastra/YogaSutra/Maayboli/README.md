# Maayboli: Patanjali Yogasutra in Marathi

A Marathi series on Patanjali's Yoga Sutras on the Maayboli site. Copies of the pages were once kept here as PDFs.
They are not in this repository any more, because they belong to their authors. Read them at the source (the four
parts, in order):

- https://www.maayboli.com/node/12263
- https://www.maayboli.com/node/12291
- https://www.maayboli.com/node/12306
- https://www.maayboli.com/node/12307

See [NOTICE.md](../../../NOTICE.md) for how this repository treats third-party material. If you are the author and
want something changed, open an issue.
