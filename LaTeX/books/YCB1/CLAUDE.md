# CLAUDE.md: YCB1 textbook

Rules for this book only. The working rules (notes first, fact-check gate, licence, picture policy) are in
`AUTHORING.md`; read it before any change. Shared rules: `../../../CLAUDE.md` (repo) and
`../../../../Publications/Books/CONVENTIONS.md`, "All book projects" (layout, naming, stages, covers, proposal and
review locations).

- `docs/Notes YCB1.md` is the master. A fact is fixed there first, then carried by hand to `workshop/` and `book/`.
- A block not yet fact-checked keeps its "Not yet fact-checked" box in the book; only the author marks a block checked.
- Chapter order lives only in `book/book_ycb1_content.tex`. Build with XeTeX (`book/make_book_ycb1.bat`).
- The Board's guidebooks and other third-party PDFs in `docs/` stay out of the public repository.
