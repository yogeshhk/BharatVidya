# Sanskrit and computing: papers and articles

A reading list on Sanskrit and computing: tokenisation, sandhi splitting and word segmentation, Sanskrit as a
programming or knowledge-representation language, machine translation, theses, and web articles on the subject. The
copies were once kept here. They are not in this repository any more, because they belong to their authors and
publishers. Many are open access: use the address where there is one, or search for the title.
