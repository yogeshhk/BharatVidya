# Samskrit

| File | What it is |
|---|---|
| [`Awesome_samskrit.md`](Awesome_samskrit.md) | A curated list of resources for learning Sanskrit |
| [`Awesome_arthashastra.md`](Awesome_arthashastra.md) | A curated list of resources on Kautilya's Arthashastra |
| [`Reading_list_papers.md`](Reading_list_papers.md) | A reading list of papers and articles on Sanskrit and computing, with links where the source has one |
